# Build this mod on GitHub

This project targets Minecraft 26.2, Fabric Loader 0.19.5, Fabric API 0.161.0+26.2, Loom 1.18-SNAPSHOT, and Java 25.

The included GitHub Actions workflow builds the mod automatically and uploads `ender-dragon-overhaul-1.0.0.jar` as an Actions artifact.

The source intentionally does not add Phantom guardians to End Crystals.
